Hidden Temple 게임 루프
1
진입 — 현재 단계 게임판 로드. 곡괭이 수 확인
2
타일 탭 — 곡괭이 1개 소모 → 서버에 tile_index 전송 → 타입(GEM/EMPTY_REWARD/EMPTY) 반환
3
결과 처리 — GEM: 수집 +1 / EMPTY_REWARD: 소량 재화 즉시 지급 / EMPTY: 먼지 이펙트
4
클리어 판정 — collected_gems >= stage_gem_target → 단계 보상 지급 → 다음 단계
5
5단계 완료 — All-Star 최종 보상 지급 → 이벤트 종료 (아이콘 소멸)
6
곡괭이 소진 — 진행도 서버 보존 → 레벨 클리어로 충전 후 이어서 진행
