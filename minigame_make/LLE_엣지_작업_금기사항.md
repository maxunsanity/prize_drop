# 🚨 LLE 엔진 엣지(Edge) 작업 금기 사항 및 표준 매뉴얼
*LLE 에디터에서 노드 연결 시 발생하는 에러를 방지하기 위한 절대 규칙*

---

## 1. 🚫 절대 금기 사항 (Critical Don'ts)

### 1-1. 트리거(Trigger) 노드와 자원(Resource) 노드 직결 금지
- **에러 현상:** "이 연결은 현재 노드 타입 규칙과 맞지 않습니다." 경고 발생.
- **상세:** `type: trigger` 또는 `type: action` 노드에서 `type: resource` 엣지를 사용하여 `resource` 노드로 선을 연결하는 것은 엔진 규칙 위반입니다.
- **올바른 방법:** 
  - 트리거 노드 내의 **`attributes`** 배열에서 `dice = dice - 1` 또는 `gold = gold + 1`과 같이 직접 수식으로 변수를 제어해야 합니다.
  - 시각적인 자원 흐름을 보여주고 싶다면 `reward`(보상)나 `disposal`(처분) 타입의 노드를 중간에 사용해야 합니다.

### 1-2. 수동 레이아웃 핸들(Handles) 임의 초기화 금지
- **에러 현상:** AI가 JSON을 재생성할 때 핸들 정보를 빠뜨리면, 사용자가 에디터에서 커스텀하게 꺾어놓은 모든 연결선이 겹치거나 초기화됨.
- **절대 규칙:** 
  - 기존 JSON의 `edges` 배열에 있는 `sourceHandle`, `targetHandle` 값을 반드시 유지해야 합니다.
  - 엣지 ID 형식을 `xy-edge__<sourceId><Handle>-<targetId><Handle>` 표준을 따라야 사용자가 에디터에서 선을 자유롭게 이동할 수 있습니다.

---

## 2. ✅ 노드 타입별 자원 처리 표준 (Standard Patterns)

| 노드 타입 | 자원 처리 방식 | 엣지 타입 | 비고 |
|---|---|---|---|
| **Trigger** | `attributes` 내 수식 제어 (`key: value`) | `exec` | 가장 안전하고 확실한 방식 (코딩 방식) |
| **Reward** | `resource` 노드로 연결 가능 | `resource` | 보상 획득 시 시각적 흐름 표현 가능 |
| **Disposal** | `resource` 노드로 연결 가능 | `resource` | 자원 소모(버리기) 시 시각적 흐름 표현 가능 |
| **Action** | `attributes` 내 수식 제어 | `exec` | 플레이어 행위 시 변수 즉시 반영 |

---

## 3. 🛠 AI 작업 지침 (AI Working Rules)

1. **레이아웃 보존:** 사용자가 업로드한 JSON을 수정할 때, 노드의 `position` (x, y) 좌표와 엣지의 `handle` 정보를 절대 변경하지 않는다.
2. **변수 선언 강제:** 모든 자원 변수(dice, gold 등)는 반드시 `n-init` 트리거 노드에서 초기화되어야 `Unknown Name` 에러를 방지할 수 있다.
3. **자원 시스템 오남용 방지:** 엔진이 지원하지 않는 노드 간 자원 엣지 연결을 시도하지 않는다. (특히 트리거 -> 자원 노드 연결 절대 금지)
