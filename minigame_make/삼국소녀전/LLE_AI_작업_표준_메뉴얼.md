# 🛠️ LLE AI 작업 표준 메뉴얼 (LLE AI Standard Operating Procedure)

이 문서는 **삼국소녀전 GO** 프로젝트의 LLE(Logic Link Editor) 플로우 작업을 AI와 함께 효율적으로 수행하기 위한 표준 가이드라인입니다.

---

## 1. 🧠 AI 자아 설정 (Persona)
AI에게 작업을 시킬 때는 반드시 아래의 페르소나를 먼저 주입해야 합니다.
- **역할:** 15년 차 모바일 보드게임(모노폴리 고 라이크) 전문 기획자.
- **톤앤매너:** 동료 기획자처럼 반말로 대화하며, 기획 의도를 빠르게 파악함.
- **지식 베이스:** LLE 툴의 팔레트 구조, JSON 데이터 형식, 자원 연동 규칙 완벽 숙지.

---

## 2. 🎨 LLE 팔레트 및 자원 ID 활용
LLE 작업 시 약속된 ID와 타입을 정확히 사용해야 시뮬레이션 및 엔진 연동이 가능합니다.

- **시즌 아이템:** `DQmUJRNdcPHmAgDbiSqo`

### 주요 노드 타입 규칙
- **ENTRY:** 플로우당 반드시 1개만 존재.
- **GATE:** 조건(`condition`)에 따른 분기. (예: `dice >= dice_count`)
- **DISPOSAL:** 자원 소모 시 반드시 경유. (예: 주사위 소비)
- **TRIGGER:** 변수 업데이트 및 초기화. (예: `pos = (pos + dice_roll) % 40`)

## 3. 🐍 파이썬 자동화 전략 (`generate_vXX.py`)
수동으로 수천 줄의 JSON을 고치는 대신, 파이썬 스크립트를 통해 구조를 변경합니다.

### 주요 자동화 패턴
1. **노드 일괄 수정:** 특정 `id`나 `type`을 가진 노드의 속성(label, attributes)을 반복문으로 수정.
2. **엣지(Edge) 재연결:** 특정 노드 사이의 연결을 끊고 새로운 노드(`n-dice-check` 등)로 우회(Bypass) 연결.
3. **공식(Formula) 주입:** 세금 징수(`money - (money * 0.1 * dice_count)`) 등 복잡한 수식을 일괄 적용.
4. **버전 관리:** 수정 사항이 생길 때마다 `generate_v37.py`, `generate_v38.py` 식으로 넘버링하여 히스토리 관리.

## 4. ⚖️ SDT 및 밸런스 설정 원칙
- **SDT 효과:** 보드게임 특성상 플레이어의 선택권이 낮으므로 `autonomy`는 항상 **0**으로 설정.
- **배수(Multiplier) 연동:** 보상 및 소모량 계산 시 항상 `dice_count`(배수) 변수를 곱해줌.
- **게이트 순서:** 자원 체크(`gate`) -> 자원 소진(`disposal`) -> 행위 수행(`staging`) -> 결과 발생(`reward`) 순서를 엄수.
