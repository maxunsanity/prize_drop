# 1-Line Slot Machine (Lucky Dog Edition) Spec MD v2

이 문서는 'Blank Paper Sketch' 스타일의 1라인 슬롯머신 게임 제작을 위한 상세 명세서입니다. v1의 단순한 구조를 넘어, 특정 레이아웃과 애니메이션 피드백을 완벽하게 재현하는 것을 목표로 합니다.

## 1. 디자인 원칙 (Design Pillars)
- **Aesthetic**: 'Blank Paper Sketch' 컨셉.
- **Color Palette**: 무채색 위주. 배경 `#faf8f5`, 잉크 `#222222`. 컬러 사용은 최소화(이모지만 컬러).
- **Stroke & Shadow**: 모든 주요 요소는 `4px solid #222` 테두리와 `4px 4px 0 #222` 형태의 블록형 그림자를 가짐.
- **Typography**: 굵고 투박한 Sans-serif 계열 사용.

## 2. 레이아웃 상세 명세 (Layout Specs)
- **전체 컨테이너 (#app)**: 390x844 (Mobile Portrait 기준).
- **머신 프레임 (.machine-frame)**: 
    - 테두리 내부에 Mascot, Title, Reels, UI 요소 포함.
    - 상단 중앙에 Mascot(🐶) 원형 박스가 프레임 테두리에 걸쳐 배치됨.
- **슬롯 릴 영역 (#reel-container-wrapper)**:
    - 3개의 세로 릴 배치. 각 릴 사이에 검은색 구분선(`4px`).
    - **가시성**: 각 릴은 세로로 정확히 **3개의 심볼**이 보이도록 높이 계산 (Canvas Height / 3).
    - **사이드 마커**: 릴 영역 좌우 중앙에 당첨 라인을 가리키는 삼각형 포인터 배치.
- **하단 UI 영역 (#ui-bottom)**:
    - **SPIN 버튼**: 정중앙 하단에 위치한 거대한 원형 버튼(지름 약 130~140px). 
    - **BET 버튼**: SPIN 버튼 우측에 위치한 원형 또는 알약 모양 버튼. SPIN보다 작게 배치.
    - **코인 카운터 (#ui-coins)**: UI 영역 최하단 정중앙에 알약 모양(Pill shape)으로 배치. SPIN 버튼 아래에 위치하여 안정감 제공.

## 3. 핵심 메커니즘 (Game Logic)
### 3.1 결과 선결정 (Result Pre-determination)
- SPIN 버튼 클릭 시, 애니메이션 시작 전 `weighted_random` 로직을 통해 3개 릴의 결과값을 즉시 계산함.
- `sm_symbol_config.csv`의 `weight` 값을 기반으로 확률 계산.

### 3.2 릴 애니메이션 (Reel Animation)
- **속도**: 매우 스피디한 연출 (전체 시퀀스 약 1.4~1.5초).
- **순차 시작**: 릴 0(0ms) -> 릴 1(200ms) -> 릴 2(400ms) 간격으로 회전 시작.
- **순차 정지**: 릴 0(600ms) -> 릴 1(1000ms) -> 릴 2(1400ms) 간격으로 정지.
- **정밀 스냅**: 정지 시 당첨 심볼이 반드시 릴의 **가운데 칸(2번째 슬롯)**에 오도록 `offset_y` 계산 및 보정 필수.

## 4. 시각 효과 및 피드백 (FX & Feedback)
- **비행 코인 이펙트 (Flying Coins)**:
    - 당첨 시, 릴 중앙 영역에서 다수의 코인 이모지(`🐾`)가 생성됨.
    - 생성된 코인들은 곡선을 그리며 하단 중앙의 코인 카운터(#ui-coins) 위치로 날아가서 소멸됨.
    - 코인 수량은 당첨 금액에 비례하여 생성 (15~30개).
- **당첨 팝업**: 화면 중앙에 `+수량` 텍스트가 위로 솟구치며 사라지는 애니메이션.
- **릴 하이라이트**: 당첨 시 릴 영역 전체 테두리가 깜빡이는 효과.

## 5. 데이터 명세 (Data Spec)
- **sm_symbol_config.csv**:
    - `symbol_id`: 고유 식별자 (예: wild, cherry, lemon, star, seven).
    - `emoji`: 표시될 이모지.
    - `weight`: 가중치 (값이 높을수록 잘 나옴).
    - `payout_multiplier`: 3개 일치 시 배율 (WILD는 만능 기호로 작동).

## 6. 안티 패턴 (Anti-Patterns) - 주의 사항
- 릴 회전 중 결과값을 계산하는 행위 금지 (반드시 선결정).
- 버튼 클릭 시 위치가 변하거나 정렬이 깨지는 레이아웃 (Transform 시 `translateX(-50%)` 유지 주의).
- 릴의 기호가 짤리거나 2개만 보이는 현상 금지.
- 동전이 카운터가 아닌 엉뚱한 곳으로 날아가는 현상 금지.

## 7. 검수 체크리스트 (Gameplay Tests)
1. SPIN 클릭 시 1.5초 이내에 모든 릴이 순차적으로 멈추는가?
2. 당첨 심볼이 릴의 3개 칸 중 정확히 가운데 칸에 위치하는가?
3. 당첨 시 코인이 하단 카운터로 날아가는 애니메이션이 부드러운가?
4. SPIN 버튼이 어느 상태에서도 정중앙에 고정되어 있는가?
5. 모든 버튼과 카운터가 '잉크 스케치' 스타일의 테두리와 그림자를 가지고 있는가?
