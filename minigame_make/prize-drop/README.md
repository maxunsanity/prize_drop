# Prize Drop

프로젝트 스캐폴드 단계입니다. 구현·스택·실행 방법은 추후 이 파일과 `package.json`에 맞춰 채웁니다.

## 작업 방식 (디렉터 최초 지시 요약)

이 저장소에서 **Cursor·에이전트가 코딩을 시작할 때** 아래 순서를 따른다.

1. **Markdown (`*.md`)**  
   기획·인계·빌드 규칙·json-render 구조 등 **텍스트 단일 진실(SSoT)** 을 먼저 읽는다.  
   예: 루트 또는 `docs/` 아래 설계·협업 노트, 게임별 `GAME_*.md`가 생기면 그것부터 본다.

2. **HTML (`*.html`)**  
   와이어프레임·정적 스펙 페이지가 있으면 **레이아웃·카피·화면 흐름** 참고용으로 읽고 구현에 반영한다.  
   (Monopoly 예: `monopoly-board-spec.html` 같은 산출물.)

3. **JSON**  
   **저장소에 해당 파일이 실제로 있을 때만** 읽는다.  
   디렉터가 따로 주지 않았거나 경로에 파일이 없으면 **읽지 않고**, 없는 JSON을 **추측·생성해서 근거 삼지 않는다**.  
   (빌드/번들 manifest, 게임 데이터, 에이전트용 프로젝트 설정 등 **레포에 포함된 것**만 대상으로 한다.)

요약하면: **md + html로 맥락을 잡고 코드에 옮기고**, **json은 “있을 때만” 열어본다.**
