# LLE RPG 전투 시스템 3단계 기획서

## 개요

2단계 기본 턴제 전투를 기반으로 몬스터 데이터, 레벨업, 스킬 시스템을 추가한 실제 RPG에 가까운 전투 시뮬레이션입니다.

## 데미지 계산 공식

```
플레이어 → 적:
damage = player_atk + rand.d6() - enemy_def (최소 1)

적 → 플레이어:
damage = enemy_atk + rand.d6() - player_def (최소 1)
```

## 전체 흐름

### 기본 순환 구조
```
일반몹 전투 (최대 3회)
  → 처치 보상 (exp + 골드)
  → 레벨업 체크
     레벨업 O → 레벨업 화면
                [계속 사냥] → 일반몹으로 복귀
                [보스 도전] → 보스 즉시 등장 (죽을 수 있음)
     레벨업 X → 킬 카운트 체크
                3회 달성 → 킬 카운트 리셋 → 보스 등장
                미달     → 다시 일반몹

보스 전투
  → 보스 처치 보상 (exp + 골드 + 스킬 충전)
  → 일반몹으로 복귀 (킬 카운트 0부터)
```

### 레벨업 시스템
- 조건: player_exp >= exp_to_next
- 적용: level_up_config 테이블에서 스탯 증가량 참조
- 레벨업 시 체력 전체 회복
- 스킬 횟수 충전 (skill_charges_restore 만큼)
- 초과 경험치 이월: player_exp = player_exp - exp_to_next

### 스킬 시스템 (4단계 구현 예정)
- 파이어볼: 기본 공격력 + damage_bonus
- 사용 시 skill_charges -1
- skill_charges = 0이면 스킬 버튼 비활성화
- 재충전: 레벨업 또는 보스 처치 시

## 엔티티 참조 방식

초기화 노드에서 직접 수치를 쓰지 않고 엔티티 노드의 키를 참조합니다.
수치를 변경하려면 엔티티 노드의 값만 수정하면 모든 초기화가 자동 반영됩니다.

```
참조 형식: {entityKey}.{필드명}

예시:
player_atk = character.atk
enemy_hp   = goblin.hp
hp_gain    = levelup.hp_gain
```

| 엔티티 | entityKey | 테이블 |
|---|---|---|
| 캐릭터 | character | character_config |
| 보스 | boss | monster_boss |
| 고블린 | goblin | monster_normal |
| 파이어볼 | fireball | skill_fireball |
| 레벨업 | levelup | level_up_config |
