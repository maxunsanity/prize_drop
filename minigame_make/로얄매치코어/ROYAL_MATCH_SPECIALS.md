# 로얄 매치 특수 블록 기획 레퍼런스

## 특수 블록 4종

### 1. 로켓 (Rocket) = STRIPED_H / STRIPED_V
- **획득**: 같은 색 4개 일렬 매치
- **효과**: 가로 로켓 → 가로 한 줄 전체 제거 / 세로 로켓 → 세로 한 줄 전체 제거
- **특징**: 가장 기본, 장애물 제거 효율 좋음, 연쇄 시작용

### 2. TNT
- **획득**: 같은 색 5~6개 L자 또는 T자 매치
- **효과**: 주변 넓은 범위 폭발 (3×3 또는 그 이상)
- **특징**: 공간 압축 제거에 강함, 좁은 맵에서 효율 좋음

### 3. 프로펠러 (Propeller)
- **획득**: 같은 색 4개 정사각형(2×2) 매치
- **효과**: 랜덤 목표 지점으로 날아가 제거 (우선 타겟: 목표 오브젝트 > 장애물 > 접근 어려운 위치)
- **특징**: 접근 어려운 칸 처리 특화, 자동 타겟팅

### 4. 라이트 볼 (Light Ball) = COLOR_BOMB
- **획득**: 같은 색 5개 일렬 매치
- **효과**: 선택한 색상의 모든 블록 제거
- **특징**: 가장 강력한 단일 특수 블록, 후반 스테이지 핵심

---

## 특수 블록 조합 효과 (시너지)

| 조합 | 효과 |
|---|---|
| 로켓 + 로켓 | 가로+세로 십자 전체 제거 |
| 로켓 + TNT | 광역 다중 줄 제거 (3행+3열) |
| TNT + TNT | 초대형 폭발 (5×5) |
| 프로펠러 + 로켓 | 다중 로켓 자동 생성 |
| 프로펠러 + TNT | 다수 TNT 생성 후 폭발 |
| 라이트 볼 + 로켓 | 동일 색 블록 전체를 로켓으로 변환 |
| 라이트 볼 + TNT | 동일 색 블록 전체를 TNT로 변환 |
| 라이트 볼 + 프로펠러 | 동일 색 블록 전체를 프로펠러로 변환 |
| 라이트 볼 + 라이트 볼 | 전체 맵 제거 |

## 로얄 매치 설계 특징

### 1. 자동 연쇄 중심 구조
- 특수 블록 생성 빈도가 높음
- 연쇄 폭발이 지속적으로 이어짐

### 2. 실패 스트레스 완화
- 마지막 순간 역전 가능성 제공
- 계속 플레이하고 싶게 만드는 구조

### 3. 후반 메타 구조
- 초반: 일반 매치 중심
- 후반: 특수 블록 조합 중심 (특수 생성 → 조합 유도 → 연쇄 폭발 → 대량 제거 → 추가 연쇄)

### 4. UX/연출 핵심
- **생성 예고 연출**: 블록 흔들림 + 빛 강조 + 슬로우 모션
- **조합 유도 UX**: 특수 블록 근처 강조 효과, 조합 가능 상태 시각적 유도
- **자동 목표 타격**: 프로펠러가 목표 우선 공격 → 플레이어가 전략적으로 느끼게 설계
- **연쇄 카메라 연출**: 화면 확대 + 진동 + 폭발 딜레이 + 연쇄 사운드 강화
