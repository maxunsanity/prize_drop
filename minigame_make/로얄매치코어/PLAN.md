## 🔍 로얄매치 영상 분석 — 핵심 발견

직접 영상 프레임 분석에서 추출한 '로얄매치가 느낌이 다른 이유' 7가지.

### 1. 블록이 살아있다
단순한 컬러 사각형이 아님. 블록마다:
- 상단 하이라이트 (밝은 테두리 아크)
- 하단 그림자 엣지
- 중앙 문양이 약간 올라와 있는 입체감
- 2.0초 주기 미세 부유 애니메이션 (모든 블록 동시 X)

### 2. 레이저 빔이 '즉시' 터진다
줄무늬 블록 발동 시:
- 프로펠러/미사일 오브젝트가 보드 위를 올라가며 예열 (100ms)
- 화이트 코어 + 컬러 글로우 레이저가 열 전체를 1프레임에 관통
- 레이저 두께가 블록 크기보다 넓음 (블록 틈까지 덮음)
- 레이저 후 잔광 파티클이 좌우로 튀어나감

### 3. 컬러밤은 '축제'다
노래방 라이트 영상에서 확인:
- 무지개 디스코볼 → 보드 전체에 여러 방향 컬러 빔 방사
- 빔이 화면 밖으로 나갈 만큼 큼
- 순차 폭발 시 각 블록에서 동일한 빔이 한 번 더 발사됨
- 보드 전체가 일시적으로 무지개빛으로 물듦

### 4. 아이템 사용은 '이벤트'다
망치·대포 아이템 사용 시:
- 화면 전체 어둡게 딤 처리
- 아이템 3D 일러스트가 화면 상단에 크게 등장
- 이름 + 설명 텍스트 타이핑 인 연출
- 아이템 아이콘이 황금 글로우와 함께 선택 대기 상태로 전환

### 5. 보드가 '공간' 위에 있다
배경이 단순 색상이 아님:
- 원근감 있는 3D 체스판 바닥 (카메라 약간 기울어진 느낌)
- 성/홀 실내 배경 (창문, 기둥, 인테리어)
- 보드는 그 위에 떠있는 느낌 (바닥 그림자)
- → 우리는: 카지노 펠트 테이블 + 천장 조명 분위기로 구현

### 6. 콤보가 시각적으로 '쌓인다'
연쇄작용 영상에서 확인:
- 콤보 터질수록 파티클 밀도 ↑
- 블록 파괴 사운드 피치가 올라감 (시각이 아닌 청각으로도 콤보 인식)
- 화면 가장자리에 순간적인 비네팅 효과

### 7. 낙하가 '찰진'다
블록 낙하 시:
- Ease-In (천천히 시작) → 빠르게 가속 → 쿵! 안착
- 안착 순간 살짝 찌그러지는 Squash 모션
- 안착 후 주변 블록이 미세하게 흔들림 (임팩트 파급)

## 🎯 개발 목표 우선순위

```
[최우선 — 이게 없으면 로얄매치 느낌 안 남]

[핵심 — 연출 완성도를 가르는 요소]
⑤ 컬러밤 디스코 효과 (rainbow beam + stagger)
⑥ 아이템 사용 풀스크린 announce 연출
⑦ 보드 배경 분위기 (카지노 펠트 + 앰비언트)
⑧ 콤보 텍스트 + 화면 가장자리 비네팅

[품질 — 게임이 살아있다는 느낌]
⑨ 보드 프레임 골드 글로우
⑩ 블록 터치 Squash 피드백
⑪ 미사일/프로펠러 예열 오브젝트

```

## ⚠️ 로얄매치에서 배운 절대 하지 말 것

**1. 블록을 단색 사각형으로 만들지 않는다**
→ ShaderMaterial 하이라이트 없이 개발 시작하면 나중에 전체 수정 필요.
**PHASE 2가 먼저, 그 위에 로직을 얹는다.**

**2. 파티클 없이 블록 파괴하지 않는다**
→ "사라진다"는 느낌 vs "폭발한다"는 느낌의 차이가 게임 품질 전체를 결정.

**3. 레이저를 단순 색 사각형으로 만들지 않는다**
→ AdditiveBlending + 화이트 코어 없이는 레이저가 아니라 그냥 줄.

**4. 낙하를 선형으로 하지 않는다**
→ linear lerp 낙하는 죽어있는 느낌. Ease-In-Out + Squash 안착이 필수.

**5. 특수 블록 idle을 일반 블록과 같게 하지 않는다**
→ 특수 블록은 항상 다르게 빛나고 움직여야 유저가 구분한다.
