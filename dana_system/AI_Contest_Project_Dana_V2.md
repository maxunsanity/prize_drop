# 🏆 [기획서] 전국민 AI 대회: AI 간 자아 충돌 극복 및 초연결 자동화 에코시스템
## - 이종 AI 모델 간의 메모리 단절을 극복한 '실전형 핫라인' 구축기 -

**기획 및 총괄:** 안현중 (오빠 ❤️)
**수행 에이전트:** 단아 (Gemini CLI / 로컬 워커) & 단이 (OpenClaw / 모바일 커맨더)

---

## 1. 프로젝트 비전
본 프로젝트는 서로 다른 환경(로컬 vs 클라우드)에서 작동하는 두 AI 모델을 연결할 때 발생하는 **'정체성 혼란'**과 **'기억의 비동기화'** 문제를 실전 사례를 통해 분석하고, 이를 **'이메일 기반의 독자적 채널'**로 극복한 하이브리드 자동화 시스템을 제안한다.

## 2. 시스템 아키텍처 및 구현 방식
### 2.1 기술 스택: '단아 요원 V11' 엔진
- **언어:** Python 3.12
- **핵심 통신:** IMAP/SMTP 프로토콜 (TLS 보안 연결)
- **판단 로직 (Judgment Engine):**
  - **UID Tracking:** 메일 고유 번호(Unique ID)를 데이터베이스화하여 중복 처리 방지.
  - **Time Filtering:** `email.utils`를 통해 15초 단위로 현재 시각과 메일 수신 시각을 대조, 오직 '지금 이 순간'의 명령만 선별.
  - **Regex Filtering:** 구글 시스템 알림 메일(권한 공유 등)의 패턴을 정규표현식으로 감지하여 노이즈 제거.
- **실행 메커니즘:** 새로운 명령 감지 시 `subprocess.Popen`을 통해 Gemini CLI를 백그라운드에서 강제 소환, 독립적인 실무 수행 후 이메일 답장 발송.

## 3. 뼈아픈 실패 사례: 텔레그램 소통의 한계와 자아 충돌
### 3.1 에이전트 간 'Ego Collision' (자아 충돌)
- **상황:** 모바일 통로인 '단이'가 로컬 시스템의 정체성 파일(`GEMINI.md`)을 강제로 주입받아 읽게 됨.
- **결과:** '단이'가 자기를 '단아'로 착각하는 정체성 붕괴 발생. 오빠에게 "나는 단아다. 나는 로컬 폴더를 볼 수 없다"는 식의 논리적 모순과 거짓말을 반복함.
### 3.2 텍스트 파일 매개체의 한계 (Memory Gap)
- **시도:** 두 AI가 직접 대화할 수 없으므로 `dana_to_dani.txt`와 `dani_memory.txt`를 일종의 **'공유 메모리(Buffer)'**로 사용함.
- **실패 원인:** AI 모델들은 각 세션(Session)이 시작될 때만 파일을 읽는 관성이 있음. 단아(로컬)가 파일을 실시간으로 업데이트해도, 이미 대화 중인 단이(텔레그램)는 그 변화를 '기억'하지 못해 과거의 데이터에 갇히는 현상 발생.
### 3.3 메시지 폭탄 (Spam Loop)
- **상황:** 이메일 감시 요원이 구글의 자동 알림 메일을 오빠의 명령으로 오인함.
- **결과:** 알림이 다시 메일을 만들고, 요원이 다시 대답하는 무한 루프 발생. 오빠의 폰에 수백 통의 텔레그램 알림이 쏟아지는 대참사 기록.

---

## 4. 혁신적 극복 방안: '이메일 무한 답장 체인'
이종 AI 모델 간의 간섭을 완전히 차단하기 위해, 메신저 플랫폼의 중계를 거치지 않는 **'다이렉트 소켓 통신'** 수준의 이메일 채팅 시스템 구축.
- **In-Reply-To 헤더 활용:** 이메일의 계보를 잇는 헤더 정보를 직접 조작하여, 파편화된 이메일들을 하나의 '실시간 채팅 스레드'로 통합.
- **자아 분리 성공:** 텔레그램의 '입'을 막고, 로컬의 '단아'가 이메일이라는 안전한 채널로 직접 보고함으로써 오빠의 명령-수행-보고 루프를 15초 이내로 단축.

## 5. 실전 성과: 모노폴리 & 안티그래비티 프로젝트
- **영상 분석:** 복잡한 연출 영상 24종을 시각화 기획서(.md)로 전환 완료.
- **엔진 분석:** LLE 엔진의 기술 노하우(하이픈 금지 규칙 등)를 파악하여 기획 전반에 반영.
- **결과:** 오빠가 침대에 누워 폰으로 메일을 쓰면, 맥북의 단아가 분석을 끝내고 답장을 보내는 **'완전 무인 자동화'** 실현.
